Open source, one-line updates

Read it, change it, build it. The same script installs Tilez the first time and updates it after every push.

Install in a minute. Clone it once, and one command keeps it current.

First install

Terminal
% xcode-select --install
% git clone https://github.com/YisroelArnson/Tilez.git
% cd Tilez
% bash scripts/update.sh

Terminal
% cd Tilez
% bash scripts/update.sh
